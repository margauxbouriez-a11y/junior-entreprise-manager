Comment arrivent les commandes ?

Chaque commande part vers le webhook n8n, qui envoie un mail à la liste (avec le numéro de commande et le détail) et un récapitulatif à l'étudiant. Le workflow prêt à importer est dans n8n/commandes-workflow.json.

Pour suspendre un produit (rupture, stand fermé), décochez « Dispo » dans le catalogue : il apparaît « Épuisé » sur le site.

Publication automatique

Quand elle est activée, chaque modification faite ici (événements, stands food, membres, stocks…) est mise en ligne automatiquement pour tout le monde, en une minute environ. Chaque membre l'active une fois sur son téléphone ou son ordinateur.

  1. Sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access : Only select repositories → …. Permissions : Contents → Read and write. Expiration : la fin de la campagne.
  3. Copiez la clé générée (elle commence par github_pat_), collez-la ci-dessous. Partagez-la aux membres de la liste en privé uniquement.

Ce code protège le budget, les stocks et les adresses des abonnés : ils sont chiffrés avec lui. Si vous le changez, prévenez tous les membres.
